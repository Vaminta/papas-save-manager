Papa's Save Manager (PSM) allows you to backup save data for the flash games produced by Flipline Studios hosted on [Coolmath Games](https://www.coolmathgames.com/papas-games), [CrazyGames](https://www.crazygames.com/t/papa) and [Poki](https://poki.com/en/papas). Backed-up saves can be restored even after browser data is completely erased. Saves can also be copied to different devices.
